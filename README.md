# Rally Around Taiwan — hosting package

GitHub Pages root for https://rally.feeltaiwan.com (Wix DNS: CNAME `rally` → `<account>.github.io`).
`index.html` is the built game (`07 build/v17`, `make-deploy.py --launch`): the launch CONFIG (campaign rally-2026, the Pacific entry window, no Reset), its images in `img/`. Do not edit by hand — rebuild and replace the whole folder (img/ names are content hashes).
Preview before opening: `https://rally.feeltaiwan.com/?preview=<CONFIG.previewKey>` (test data: campaign rally-2026-test).
